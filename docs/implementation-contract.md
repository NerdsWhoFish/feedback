# Implementation contract

Internal coordination reference for the v1 implementation. OpenAPI is the public contract.

- Module: github.com/NerdsWhoFish/feedback. Go stdlib ServeMux, pgxpool.
- All IDs are UUID strings. JSON snake_case. List responses: {items: [], limit: 50, offset: 0}; limit maximum 100. Errors: {error: {code: string, message: string}}.
- Root owns internal/auth, internal/config, internal/telemetry, cmd/feedback and web/embed.go. Domain agent owns internal/api, internal/store, migrations and tests. UI agent owns web excluding embed.go. Docs agent owns README, docs/openapi.yaml, ADRs, Dockerfile, compose.yaml, Makefile, .github and deploy.
- API entry: `api.New(pool *pgxpool.Pool, logger *slog.Logger) *api.Server`; `Register(mux *http.ServeMux, require func(http.Handler) http.Handler)`. `RunWebhooks(ctx context.Context)`. Auth registers /auth/login, /auth/callback, POST /auth/logout and GET /api/v1/me; me returns auth.Principal directly including csrf_token. Auth Require applies authentication, CSRF and key rate limiting; domain handlers enforce project and operation authorization.
- Auth principal: auth.FromContext(r.Context()), fields UserID, Email, Name, Role, KeyID, KeyType (app|assistant or empty for browser), AppName, CSRF. Admin() only browser admin. Browser() only session user. No testing bypass in production.
- Shared schema required by auth: users(id uuid primary key default gen_random_uuid(), email text, name text, role text default 'member'); identities(issuer text, subject text, user_id uuid, primary key(issuer,subject)); sessions(token_hash text primary key,user_id uuid,csrf_token text,expires_at timestamptz); oidc_states(token_hash text primary key,nonce text,verifier text,expires_at timestamptz); api_keys(id uuid, name text, key_type text, app_name text, key_hash text unique, revoked_at timestamptz, created_at timestamptz); key_projects(key_id uuid,project_id uuid). Session hashes use lowercase SHA256 hex. Root adds auth SQL migration if necessary; domain owns base schema.
- Browser identity issuer is actual OIDC issuer; app issuer is 'app:'+app_name. No linking by email. Memberships authorize verified browser email, never app email. Admin role is refreshed from configured administrator emails on every request, not trusted from app-provided identity or stored role alone.
- Store entry: store.Migrate(ctx,pool) error using embedded versioned SQL and advisory locking.
- GET /api/v1/projects; POST /api/v1/projects admin {slug,name,description,public_status_page}; PATCH /api/v1/projects/{project} same fields. Project object {id,slug,name,description,public_status_page}.
- GET /api/v1/projects/{project}/requests?status=&external_id=&limit=&offset=; POST same {title,description,end_user?:{external_id,email,name}}. Browser source portal; app source app:<app_name>; assistant submissions forbidden.
- GET /api/v1/requests/{id} returns {id,project_id,title,description,status,source,votes,created_at,updated_at,public_token?,comments:[],history:[]}. App reads require external_id query and ownership in app namespace. List items same request core fields. Public token only admin and browser author.
- POST /api/v1/requests/{id}/comments {body,internal}; POST /api/v1/requests/{id}/status {status}; PUT and DELETE /api/v1/requests/{id}/vote. Members can only public comment/vote; app keys read and submit only; assistant comments (public/internal) and permitted transitions only.
- Assistant transitions: approved_for_build -> in_progress, in_progress -> shipped, in_progress -> approved_for_build. A return to approved_for_build may only release an already authorized in_progress request, never approve open/planned/declined. Admin can select all statuses. History entries {id,from_status,to_status,actor_name,created_at}; comments {id,body,internal,author_name,created_at}.
- GET /api/v1/projects/{project}/changelog; POST same admin or assistant {title,body,request_ids:[]}; linked requests must belong to project and be shipped. Entries {id,title,body,created_at,request_ids:[]}.
- GET /api/v1/projects/{project}/memberships; POST same admin {email}; DELETE /api/v1/projects/{project}/memberships/{email}.
- GET /api/v1/keys; POST same admin {name,key_type,app_name,project_ids:[]}; returns metadata plus token shown once. DELETE /api/v1/keys/{id} revokes. App names validated lowercase slug, stable namespaces even across key rotation.
- GET /api/v1/projects/{project}/webhooks; POST same admin {url,events:[]}; returns metadata plus secret shown once. DELETE /api/v1/projects/{project}/webhooks/{id}; GET /api/v1/projects/{project}/deliveries. Only public HTTPS destinations, SSRF-safe DNS validation on each dial, no redirects, bounded timeout. Durable transactional event outbox with retry log; never expose webhook secret on reads. Worker signing secrets encrypted at rest with server WEBHOOK_ENCRYPTION_KEY (base64 32 bytes), API keys hash only. Server creation can accept webhook key via setter if needed, coordinate with root.
- GET /api/v1/public/requests/{token} anonymous only when project public_status_page true. Returns only title,status,public comments without authors,history without actors. Browser page /s/{token}. No PII, IDs, descriptions, source or internal comments.
- Public landing/auth SPA at /. Project navigation may use state; public page direct URL must work. Text content rendered as plain text, no HTML.
